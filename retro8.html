1. System Architecture & Hardware Overview

The RETRO-8 is an 8-bit fantasy processor architecture featuring a 4-bit Address Bus, an 8-bit Data Bus, and direct LED visual diagnostics.

  • Main Accumulator (Reg A): 8-bit register holding computation results. Output on the red LED array.
  • Program Counter (PC): 4-bit register tracking execution location in memory (0x0 to 0xF). Output on green LEDs.
  • Status Flags: Amber LEDs indicate CPU status:
    • Z (Zero Flag): Set when an operation yields 0x00.
    • C (Carry/Borrow Flag): Set when addition exceeds 255 (overflow) or subtraction drops below 0 (underflow).
  • RAM: 16 Bytes of addressable internal storage (0x0 through 0xF).

2. Operating Workflows (Step-by-Step)

Workflow A: Powering On the System

  • Click the red POWER I/O rocker switch in the top right.
  • Ensure system boot diagnostics output "SYSTEM POWERED ON. READY." on the green CRT monitor.

Workflow B: Manual Instruction Programming (Physical Switches)

  • Set the ADDRESS SWITCHES (4-bit array, A3-A0) to select target RAM cell (e.g., 0000 for Address 0x0).
  • Set the DATA / INSTRUCTION SWITCHES (8-bit array, D7-D0) to the byte opcode you wish to program.
  • Click DEPOSIT IN RAM. The terminal will log confirmation of entry.
  • Advance the address switches to the next memory address and repeat.

Workflow C: Inspecting Memory Contents

  • Toggle the address switches to desired target location.
  • Click EXAMINE RAM. The contents stored in that RAM address will print to the CRT log.

Workflow D: Executing & Controlling Programs

  • Click STEP to execute a single instruction at current Program Counter (PC).
  • Click RUN / STOP to start automatic CPU clock ticking at ~2.5 Hz. Click again to freeze execution.
  • Click RESET PC to set Program Counter back to address 0x0 without wiping RAM.
  • Click CLEAR RAM to clear memory and reset registers.

3. Instruction Set Architecture (ISA)

Instructions are 8-bit words structured as: [4-bit Opcode] [4-bit Operand/Immediate Value].

Opcode Mnemonic Hex Example Operation & Effect
0x0_ NOP 0x00 No Operation. Passes clock cycle cleanly.
0x1X LDA imm 0x15 Load Immediate X into Register A. Sets Zero flag if X=0.
0x2X ADD imm 0x24 Add Immediate X to Reg A. Sets Carry flag on overflow (>255).
0x3X SUB imm 0x32 Subtract Immediate X from Reg A. Sets Carry flag on underflow (<0).
0x4X AND imm 0x43 Bitwise AND Reg A with X. Updates Zero Flag.
0x5X OR imm 0x5F Bitwise OR Reg A with X. Updates Zero Flag.
0x6X XOR imm 0x6A Bitwise XOR Reg A with X. Updates Zero Flag.
0x70 NOT 0x70 Bitwise invert all bits in Reg A. Updates Zero Flag.
0x8X JMP addr 0x80 Unconditional jump: set Program Counter (PC) directly to target address X.
0x9X JZ addr 0x94 Conditional jump: sets PC to address X ONLY IF Zero Flag (Z) is set.
0xF0 HALT 0xF0 Stop program execution clock. Prints execution complete message.

4. Example Programs & Walkthroughs

Example 1: Boolean Logic & Bit Inversion

Calculates (5 AND 3) XOR 15.

  • [0x0] 0x15 : Load 5 into Reg A (Reg A = 00000101)
  • [0x1] 0x43 : AND with 3 (Reg A becomes 00000001)
  • [0x2] 0x6F : XOR with 15 (Reg A becomes 00001110 / 0x0E)
  • [0x3] 0xF0 : HALT

Example 2: Arithmetic with Carry/Zero Flag Checking

Calculates 4 + 7 - 2.

  • [0x0] 0x14 : Load 4 into Reg A
  • [0x1] 0x27 : Add 7 (Reg A = 11 / 0x0B)
  • [0x2] 0x32 : Subtract 2 (Reg A = 9 / 0x09)
  • [0x3] 0xF0 : HALT

Example 3: Conditional Branching & Loops

An infinite binary counter incrementing by 1 in address zero.

  • [0x0] 0x21 : ADD 1 to Reg A
  • [0x1] 0x80 : JMP back to address 0x0
